REFLECTION
Which county has the most stations, and how did you find out?

There is a four-way tie for the most stations: Cass, Clinton,
Tippecanoe, and White each have 3. I found this by piping the county
column into 'sort | uniq -c', which counts how many times each county
appears:
    tail -n +2 whin_stations.csv | cut -d, -f3 | sort | uniq -c
To see the top counties directly, I can add '| sort -rn':
    ... | sort | uniq -c | sort -rn
